# /save-learnings

**Purpose:** Document project learnings, reusable patterns, and improvements for future reference

**When to use:** After project complete and quality approved; before handoff or closure

---

## Workflow

1. **Workflow insights**
   - What process worked well?
   - What slowed us down?
   - What should change for next project?
   - Tool/practice effectiveness?

2. **Design insights**
   - How did the visual direction perform?
   - Client reaction to design choices?
   - Typography/color system observations?
   - Motion language effectiveness?
   - What surprised us about the direction?

3. **Component reuse**
   - Which components are reusable?
   - Which were project-specific?
   - How to adapt for other projects?
   - What worked well?
   - What needs improvement?

4. **Image/video insights**
   - Successful prompts and patterns?
   - Generation tool performance?
   - Optimization discoveries?
   - Mobile cropping learnings?

5. **Performance insights**
   - What improved Lighthouse scores?
   - What were bottlenecks?
   - Mobile performance strategies?
   - Architecture decisions that helped?

6. **Quality insights**
   - Strongest aspects of this project?
   - Areas needing improvement?
   - Testing effectiveness?
   - QA process improvements?

7. **Team/process insights**
   - Communication improvements?
   - Approval process effectiveness?
   - Tools that accelerated work?
   - Estimation accuracy?

8. **Client-specific insights**
   - What client loved?
   - Unexpected reactions?
   - Communication that worked?
   - Future collaboration approach?

---
