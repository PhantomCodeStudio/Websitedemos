# /concept-remix

**Purpose:** Combine the strongest elements from multiple concepts into refined hybrid concepts

**When to use:** After filtering 20 concepts to top 5-7; before final selection

---

## Workflow

1. **Review top concepts**
   - Read through 5-7 strongest concepts
   - Note what makes each strong
   - Identify unique features
   - Spot overlaps and differences

2. **Identify best elements**
   - Strongest visual direction
   - Best interaction idea
   - Most compelling imagery approach
   - Best typography choice
   - Strongest motion language
   - Most differentiated aspect

3. **Create 3-4 hybrid remixes**
   - Remix A: Combine visual style 1 + interaction 2 + imagery 3
   - Remix B: Combine visual style 2 + interaction 1 + imagery 2
   - Remix C: Combine visual style 3 + interaction 1 + imagery 1
   - Each should feel like a coherent new direction

4. **Document each remix**
   - Name/concept
   - Source concepts (which parts from where)
   - Visual style + rationale
   - Typography approach
   - Color direction
   - Motion language
   - Interaction concept
   - Imagery strategy
   - Why this remix works
   - Risks/challenges
   - Required components/tools

5. **Score each remix**
   - Client fit (1-10)
   - Originality (1-10)
   - Buildability (1-10)
   - Overall score

---

## Questions to Ask

- What if we combined the visual style of A with the interaction of B?
- Does this remix feel intentional or forced?
- Is this remix stronger than any individual concept?
- Can we build this without major new tools?
- Does it serve the client's goals?

---

## Deliverable

3-4 refined hybrid concepts, ready for final selection in /concept-select.

Each concept should have complete visual direction, not just ideas.
