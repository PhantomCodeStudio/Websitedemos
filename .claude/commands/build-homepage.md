# /build-homepage

**Purpose:** Build the website section-by-section after direction is locked and components are audited

**When to use:** After design direction approved, components classified, implementation plan ready

---

## Prerequisite

- ✓ Design direction locked in DESIGN_DIRECTION.md
- ✓ Components audited and mapped in COMPONENT_AUDIT.md + COMPONENT_MAPPING.md
- ✓ Design system defined in DESIGN_SYSTEM.md
- ✓ Motion system defined in MOTION_SYSTEM.md
- ✓ Implementation plan ready in IMPLEMENTATION_PLAN.md

---

## Build Phases

### Phase 1: Foundation (Header + Hero)
- Build header component
- Build navigation system
- Build hero section
- Add hero images/video
- Test responsive design

### Phase 2: Core Content (Main Sections)
- Build intro section
- Build services/capabilities section
- Build work/case studies section
- Build process/approach section
- Integrate typography + colors

### Phase 3: Supporting Content
- Build stats/proof section
- Build contact CTA section
- Build footer section
- Connect all links

### Phase 4: Motion Pass
- Add scroll animations
- Add hover states
- Add page transitions
- Performance test

### Phase 5: Image Optimization
- Generate all images
- Optimize to WebP/AVIF
- Test mobile crops
- Verify loading performance

### Phase 6: Mobile + Polish
- Mobile responsive pass
- Touch interaction testing
- Performance optimization
- Accessibility audit (WCAG 2.1 AA)

### Phase 7: QA + Launch
- Full quality scorecard evaluation
- Bug fixes
- Final review
- Deployment setup

---

## Section-by-Section Process

For each section:
1. Build structure (HTML/JSX)
2. Apply styling (CSS + design tokens)
3. Add responsive breakpoints
4. Test accessibility
5. Add motion/interactions
6. Optimize images
7. Document component usage

---

## Quality Gates

- Visual hierarchy clear
- Typography consistent
- Motion purposeful
- Mobile responsive
- Accessibility compliant
- Performance acceptable

---

## Deliverable

Production-ready website with all sections built, tested, and optimized.

Quality score 85+.

Ready for launch.
