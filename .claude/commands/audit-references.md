# /audit-references

## Purpose
Group accumulated visual references into style families and determine the visual direction for the project.

## What It Reads
- REFERENCE_AUDIT.md (existing references)
- reference/visual-cues/ (all images)
- DESIGN_BRIEF.md (client type, goals)

## What It Updates
- VISUAL_BUCKETS.md (new file)
- DESIGN_DIRECTION.md (new file)

## Process

1. **Review all references**
   - Look for patterns and style families
   - Group by mood, color, typography, motion

2. **Classify into families**
   - Count which families appear most
   - Note strongest/weakest references
   - Identify borrowed features

3. **Assign roles**
   - Core visual style (primary aesthetic)
   - Support style (complements core)
   - Rare-use accent (signature detail)
   - Texture source (patterns/materials)
   - Motion source (animation language)
   - Prompt source (image/video direction)

4. **Create visual buckets**
   - Document chosen style families
   - Explain why each fits
   - List what to use/avoid from each
   - Note overuse risks

5. **Define visual direction**
   - Mood statement
   - Typography direction
   - Color approach
   - Texture/material approach
   - Motion language
   - Interaction concept

## Output Format

### VISUAL_BUCKETS.md

```
## Visual Direction

### Core Visual Style: [Style Name]
- Description
- Best references
- Key visual elements
- Mood
- Risk factors
- How to prevent overuse

### Support Style: [Style Name]
- Description
- When to use
- Integration points
- Contrast with core

### Rare-Use Accent: [Style Name]
- Description
- Where to use (sparingly)
- Why it's signature
- Overuse risk

### Typography Direction
- Primary typeface(s)
- Hierarchy approach
- Moods achieved
- Contrast strategy

### Color Approach
- Primary palette
- Secondary colors
- Accent colors
- Interaction colors
- Contrast for accessibility

### Motion Language
- Transition timing
- Easing preferences
- Hover behavior
- Scroll behavior
- Page transition mood

### Image Treatment
- Photo style
- Illustration style
- Graphics approach
- Texture use
- Composition language
```

## Do Not Do
- Do not ignore references just because they're different
- Do not force everything into one style
- Do not lock direction without seeing full visual buckets
- Do not overthink - look for natural patterns
