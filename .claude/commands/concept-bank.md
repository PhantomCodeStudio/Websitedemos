# /concept-bank

## Purpose
Generate 20 different creative website concepts before committing to one direction. Creates idea diversity before filtering.

## What It Reads
- DESIGN_BRIEF.md (client info, goals)
- VISUAL_BUCKETS.md (visual style options, if available)
- COMPONENT_AUDIT.md (available components)

## What It Updates
- Creates CONCEPT_BANK.md with 20 detailed concepts

3. Brutalist modern
4. Spatial/immersive tech
5. Museum/gallery

## Concept Format

For each of 20 concepts include:

```
## Concept [#]: [Concept Name]

**Client Fit:** [Which client types benefit]

**Professional/Creative Split:** XX/XX
[Explain how this split is achieved]

**Core Visual Style:** [Primary aesthetic]
[1-2 sentence description]

**Typography Direction:** [Font strategy]
[How type serves the concept]

**Color Direction:** [Palette approach]
[Colors and meaning]

**Layout Idea:** [Structure concept]
[How content is organized]

**Motion Idea:** [Animation language]
[What moves, how, why]

**Image/Art Direction:** [Visual asset approach]
[Photography, illustration, graphics]

**Interaction Concept:** [User interaction]
[Unique interaction or engagement]

**Why It Fits:** [Client alignment]
[Connection to brief, goals, audience]

**Risk Factors:** [Challenges]
[What could go wrong]

**Difficulty:** [Low/Medium/High]
[Complexity to execute]

**Required Components:** [Component needs]
[What components needed]

**Required Tools:** [Tech stack]
[Packages, frameworks, libraries needed]

**Image Prompt Direction:** [Visual asset needs]
[Style, mood, treatment of images]

**Video Prompt Direction:** [Motion asset needs]
[Movement, speed, mood of video]
```

## Generation Rules

1. **Vary wildly** - Don't make 20 versions of the same idea
2. **Include risky ideas** - Some should push boundaries
3. **Include safe ideas** - Some should be conservative
4. **Mix style families** - Use different visual references
5. **Consider client type** - Some for business, some for creative, some hybrid
6. **Think beyond layout** - Include concepts about interaction, motion, image treatment
7. **Name clearly** - Make concept names memorable and distinct

## Do Not Do
- Do not filter yet (that's /concept-filter)
- Do not worry about feasibility yet
- Do not repeat the same concept under different names
- Do not make 20 variations of one idea
- Do not assume the visual buckets limit you

## Output
Detailed CONCEPT_BANK.md with 20 distinct, well-developed concepts ready for filtering.
